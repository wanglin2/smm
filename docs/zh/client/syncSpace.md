# 思绪思维导图同步空间配置保姆级教程~

思绪思维导图是一个本地化存储的思维导图，本身不提供云存储和跨设备同步的功能，但是最近版本支持了WebDAV协议的同步功能，本文就来详细介绍一下如何使用。

国内支持WebDAV协议的网盘产品很少，我只知道坚果云，如果你有知道有其他的，欢迎评论区留言~

首先注册或登陆坚果云：[https://www.jianguoyun.com/](https://www.jianguoyun.com/ "https://www.jianguoyun.com/")

然后下载安装客户端：[https://www.jianguoyun.com/s/downloads](https://www.jianguoyun.com/s/downloads "https://www.jianguoyun.com/s/downloads")

安装完打开客户端并登陆后，点击左下角的【设置】：


![](https://files.mdnice.com/user/19028/58eda3bc-1151-4411-be96-d72c05b2664d.png)

点击【管理】第三方应用：


![](https://files.mdnice.com/user/19028/5daf6680-1f6d-4bc6-a9d6-4374bef881e0.png)

点击【添加】：


![](https://files.mdnice.com/user/19028/5ba14b4c-113f-41a3-a4c2-7ec29c8e4848.png)

生成密码：


![](https://files.mdnice.com/user/19028/02baf45a-5436-49f8-a59d-e5d5879e0d1a.png)


然后复制生成的密码：


![](https://files.mdnice.com/user/19028/1af1a249-c469-465f-b74a-681c2b1ee6d1.png)

填写到思绪思维导图中，右上角【设置】-【同步空间】：


![](https://files.mdnice.com/user/19028/0a2dc264-4e77-4278-8c3c-8a041cf462fb.png)


用户名就是你账号的用户名：


![](https://files.mdnice.com/user/19028/8899b865-59d1-4570-a602-e0ffd920ac4a.png)

填写完成后，可以点击【测试】：

![](https://files.mdnice.com/user/19028/caf5de41-4953-48c2-8f9f-71a7e024a448.png)



提示成功了以后，就可以回到思维导图主页-【同步空间】：


![](https://files.mdnice.com/user/19028/3d808c00-0359-4cd7-8379-e8d47ead1773.png)


在【同步空间】里创建的思维导图文件就会上传到坚果云中，在其他电脑里也配置同步空间后，就可以进行同步了。

当然，坚果云免费账户一个月是有流量限制的：


![](https://files.mdnice.com/user/19028/6be66f3d-c962-400d-b833-b5bd763d66d7.png)


一般来说，简单用用完全足够，不过也需要经常关注一下使用量。

配置到此就完成了，如有其他问题，欢迎评论区留言~
