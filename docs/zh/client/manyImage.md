# 思维导图插入太多图片卡顿怎么办？

思绪思维导图节点支持插入本地图片和网络图片，如果插入的图片非常多，会带来两个问题：

1.文件体积膨胀

因为思绪是一个单机软件，所以插入的本地图片都会以base64编码的形式保存在smm源文件中，所以你会发现，如果插入了非常多的图片，smm体积会非常大，体积太大可能会带来一些问题，比如文件打开和保存时比较慢，甚至可能数据丢失。

2.思维导图编辑卡顿

编辑的时候会比较卡，甚至窗口崩溃。

那么怎么解决这两个问题呢，可以试试下面的方法：

# 1.配置图床

如果你有较强的插入图片需求，那么强烈建议配置一个图床，一次麻烦，方便永久。

可能有的人会担心图床的费用问题，其实个人使用，一年也花不了几块钱。

详细配置教程可以参考这篇：[思绪思维导图图床配置保姆级教程~](https://mp.weixin.qq.com/s/hXTKHfCnjz6jIqJuuTl8gQ)。

图片配置完成并启用后，后续添加的本地图片都会直接上传到云端，只存储一个url，可以显著减小文件体积。

![](https://files.mdnice.com/user/19028/d128bcff-cce4-40d5-a0a0-872ccffe44a1.png)


# 2.图片压缩配置

如果你不想配置图床，那么可以试试在软件的设置-基础设置里，调整一下图片的压缩参数，把压缩参数调到最大，这样可以减小图片体积，缺点是降低图片的清晰度。

这个方法只是延缓了文件体积膨胀的速度，但是插入的图片数量足够多，体积还是会很大。

![](https://files.mdnice.com/user/19028/2833a4b3-8b8e-4e26-a4b5-783e2454d98d.png)

# 3.以附件形式插入

也可以以附件的形式插入图片，这样也只是存储一个文件的本地路径，不会造成文件体积膨胀和卡顿的问题。

当然，缺点也有很多，比如无法直接在思维导图中预览图片、跨设备分享思维导图文件需要同时传递附件。

![](https://files.mdnice.com/user/19028/806cc303-49cc-4bd8-babc-7dd7386a3c9a.png)

# 4.默认收起节点

可以默认收起其他节点，只展开当前正在编辑或查看的节点，因为节点收起时就会从画布删除，所以可以减少卡顿的问题。

![](https://files.mdnice.com/user/19028/587cf1b5-260c-446d-86b4-84d111716d56.png)


# 5.开启图片懒加载

v0.19.0+支持设置开启图片懒加载，入口在编辑窗口-右侧【设置】侧边栏-图片按需加载。

开启后，会只加载当前可视区域内的图片，不可见节点的图片会被删除，可以有效降低图片占用的内存，减少卡顿问题。

![](https://files.mdnice.com/user/19028/1b1692fc-e139-4ee6-b2da-d4adb3a1acba.png)

另外，还有人咨询一个节点是否可以插入多张图片？

这个目前是不支持的，以后大概率也不会支持，唯一的方法就是通过备注，但是，只建议在配置并开启了图床的情况下在备注中插入本地图片，否则图片以base64编码的形式保存到备注中，备注编辑器大概率会崩溃。
